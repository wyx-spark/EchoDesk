English version: [`docs/en/USER_GUIDE.md`](../en/USER_GUIDE.md)。

## 一、安装与启动

### 安装版（推荐）
1. 双击 `EchoDesk-v0.2.1-Setup.exe`（`-NoModel-` 那份是同一个程序、只是不带内置模型）。
   不需要管理员权限。
2. **默认装到"安装程序自己所在的文件夹"** —— 把安装程序放进 `D:\Tools\EchoDesk\` 再双击，
   就装到 `D:\Tools\EchoDesk\`。向导里有路径选择页，想装到别处在那里改即可。
3. 向导会创建开始菜单快捷方式（勾选后也创建桌面快捷方式），最后询问是否立即启动。
   之后要卸载，走系统「应用和功能」（或开始菜单里的卸载项）。

装出来的目录结构与便携版**完全一致**：程序本体在 `app\`，你的数据与 `results\` 就在安装目录里。

### 便携版（zip 免安装）
1. 把整个 `EchoDesk-v0.2.1` 文件夹解压到任意位置（桌面、D 盘、U 盘均可）——
   不会往该文件夹以外写任何东西，删除文件夹即卸载；
2. 双击文件夹内的**「Start-EchoDesk-v0.2.1.lnk」**——这是唯一入口，
   不需要分辨 `app\EchoDesk.exe` 与 `app\backend\EchoDeskBackend.exe` 的区别
   （后者由界面自动拉起，请勿单独运行）。
   zip 里没有预置快捷方式（快捷方式记的是绝对路径，在别人机器上生成的必然是死链）——请先运行一次
   `install-complete.bat`，或直接双击 `app\EchoDesk.exe` 并接受"创建快捷方式"的询问；
3. 首次启动会依次处理三件事：
   - 若 `app\backend\models\` 里没有模型 → 询问是否下载（约 508MB，需联网）；
   - 若文件夹内没有快捷方式 → 询问是否创建；
   - 显示一次上手引导。

**两层结构**：外层（`EchoDesk-v0.2.1\`）只放快捷方式、用户数据与文档，**程序本体全部在 `app\` 里**
——外层不出现任何 exe/dll，要卸载时删掉整个文件夹即可。

### 目录结构与你需要知道的位置

下表里的路径都相对便携版**外层**目录（`EchoDesk-v0.2.1\`）。**`app\` 里是程序本体，不要往里放自己的东西；
外层才是你的数据目录**，备份与清理都以外层为准。

| 位置 | 内容 | 能不能删 |
| --- | --- | --- |
| `app\backend\config.json` | 全部配置（模型、窗口、摘要、自动化、市场） | 可删（会重建为默认值） |
| `app\backend\models\*.gguf` | 本地模型 | 可删（下次启动会询问重新下载） |
| `app\backend\session.json` | 上次对话（自动恢复） | 可删（清空历史） |
| `app\backend\browser_state.json` | 自动化的登录态（Cookie） | 可删（退出所有登录） |
| `app\backend\automation_log.jsonl` | 自动化审计日志 | 可删（建议先归档） |
| `app\backend\skills\` + `app\backend\skills_registry.json` | 已安装技能 | 建议用市场卸载 |
| `app\backend\summary_cache.json` | 长文档分段摘要缓存（可读 JSON） | 可删（下次上传重新计算） |
| `results\` | 自动化结果（按 `日期\任务名\` 分层） | 可删（建议先归档） |
| `lang\` + `app\lang\ui\` | 后端 / 界面语言包（可自行新增语言） | 不建议删（删掉会退回内置文案） |
| `ui_state.json` | 窗口位置/大小、字号、主题 | 可删（重置界面状态） |
| `snippets.json` | 常用语 | 可删 |
| `USAGE.txt` | 面向用户的结构说明 | 可删 |

**备份**：需要保留对话记录与设置时，复制 `app\backend\session.json`、
`app\backend\config.json`、`snippets.json` 三个文件即可。

**数据位置**：`ui_state.json`、`snippets.json` 与 `results\` 都在便携版**外层**目录（不在 `app\` 里）。
想让它们落到别的位置（例如 U 盘或用户目录），可以在启动前设置环境变量 `ECHODESK_DATA`
指向目标目录，程序会把用户数据写到那里。

### 没有模型也能启动

EchoDesk 不自带模型权重。本地没有模型时程序**照样启动并保持可用**——不退出、不卡住、
也不会在未经你操作前下载任何东西：

1. 状态栏显示**「无模型」**，对话框给出引导并附上模型文件夹的真实路径。
2. 不依赖推理的功能照常可用：文件解析、设置、技能市场、模型市场、会话历史；
   提问会返回引导而不是报错。
3. 三种拿到模型的方式，**都不需要重启程序**：
   * **设置 → 模型 → 模型市场** → 搜索并下载。列表显示全部 GGUF 仓库（不按硬件过滤隐藏），
     适合本机的条目标有「(推荐)」，`config.json` 里配置的模型所在仓库固定在列表最前。
   * 把 `.gguf` 文件放进 `app\backend\models\`，点**「重新扫描模型文件夹」**；
     只扫描到一个模型时会自动加载。
   * 在「本地模型库」里点已下载模型旁的**「加载」**。
4. 模型加载成功后，状态栏从"无模型"变为模型名，立刻可以对话；加载失败会给出原因并可重试，
   两种情况程序都在继续运行。

### 长文档正在分段摘要时

长文档会分段摘要。对话框会实时显示进度，而不是沉默：当前阶段、正在处理第几段共几段、
已耗时、当前段已生成多少文字。只是**偏慢**的段会被标注为偏慢并继续跑；
点停止会立刻中止，原文保留在上下文中（不会注入半份摘要），随时可以用 `/summarize` 重来。

## 二、日常问答

1. 在下方输入框输入问题，`Ctrl+Enter` 发送（`Enter` 是换行）；
2. 生成中想打断：按 `Esc` 或点 ⏹；
3. 想复制某段回答：用该条消息右下角的按钮——
   - 「📋 复制」→ 纯文本；
   - 「⧉ Markdown」→ 保留原始标记（粘到支持 Markdown 的地方会重新排版）；
   - 「</> 代码」→ 只复制代码块；
   - 也可以直接用鼠标拖选后 `Ctrl+C`。
4. 想复制整段对话：`Ctrl+Shift+C`。

### 常用指令

```
/help                 全部指令
/mode contract        切到合同审查模式（也可 /mode 5 或 /mode ct）
/file D:\合同.docx     上传文件
/summarize            对已上传的长文档手动触发全文摘要
/temp 0.3             调整生成温度
/prompt 你是财务顾问    临时改变助手角色
/search on            开启联网搜索（提问前先搜网络，需联网）
/model list           查看本地模型 / /model 别名 切换
/task list            任务型提示词模板（摘要归纳 / 合同条款审查 / 结构化抽取 / 翻译 / 代码排错 / 推理判断）
/preset light         生成参数三档预设：light（轻量）/ balanced（均衡）/ quality（高质量）
/compact              立刻压缩上下文，腾出空间
/darkmode auto        主题：on 深色 / off 浅色 / auto 跟随系统
/status               查看模型、窗口、上下文占用、KV Cache 估算与模型能力（参数量/量化/实测速度）
/about                版本号、出品方与合规文档的本机路径
/save 会议纪要         导出对话为 Markdown
/undo                 撤回最近一轮问答
/clear                清空对话与文件上下文
/exit                 退出（10 秒倒计时）
```

### 让本地小模型答得更稳

- **任务模板**：`/task list` 列出 6 个模板——摘要归纳（`summary`）、合同条款审查（`contract`）、
  结构化抽取（`extract`）、翻译（`translate`）、代码解释与排错（`code`）、推理判断（`reason`）。
  用 `/task contract` 套用（可以只写前缀，如 `/task con`），`/task off` 取消。
  模板与**当前模式叠加**生效：模式负责场景与语气，模板负责本轮的输出格式，两者冲突时以模板为准
  （提示词里写明了这条优先级）。`/prompt <文本>` 优先级最高，会盖住模式与模板——
  想恢复模板先 `/prompt reset`；`/task off` 只取消模板，不会动你设的自定义提示词。
- **回答语言**：跟随界面语言。中文界面要求简体中文，英文界面要求英文；
  若你自己加了别的语言包，模型会跟随你提问所用的语言。提示词正文本身保持中文，不影响这点。
- **每个模式都有完整的提示词**：6 个模式各自写明角色、输出格式、推理步骤、一个输入输出示例与语气，
  并共享同一段"边界与输出纪律"（不知道就说不知道、信息不足先问清最关键的一点、不编造出处）。
- **生成预设**：`/preset list` 查看；`light`（轻量，回复短、最快）/ `balanced`（均衡，默认）/
  `quality`（高质量，回复最长）会一键切换温度、top_p、重复惩罚与回复长度上限。切换结果记入配置，
  重启后仍然生效；之后再手动用 `/temp` 改温度时以手动值为准。
- **压缩上下文**：`/compact` 立刻把较早的对话压成摘要腾出空间（配置项 `context_mode` 设为
  `slide` 时改为直接丢弃最早的历史），不必等占用超过 80% 才自动触发。
- **被追问是正常的**：提问过于模糊、且既没有文件上下文也没有历史时（例如只发「这个怎么办」），
  程序会先追问你要问的对象、期望的输出形式与约束条件，而不是硬答。
  不想被追问可在 `app\backend\config.json` 里把 `clarify_vague` 改为 `false`。

## 三、场景一：审查长合同

**目标**：让本地模型基于一份几十页的合同回答问题，且不因超出窗口而丢信息。

1. `Ctrl+O` 或直接**把文件拖进窗口**（支持 docx/xlsx/pptx/pdf/txt 等）；
2. 若文件很长，EchoDesk 会自动先做**分段摘要**（对话框里能看到「正在摘要第 N/M 段」），
   完成后提示原文被压缩成了多少 token，并给出**原文指针**；
3. 提问时**提到文件**（例如「这份合同的付款条款是怎么约定的？」「有哪些违约风险？」）；
4. 若摘要粒度不够、想看细节：
   - 用 `/summarize` 重新生成一次摘要；
   - 或把合同按章节拆成几份分别上传；
   - 或临时调大 `app\backend\config.json` 的 `context_length`（越大越慢、内存占用越高，
     `/status` 会显示 KV Cache 估算）；
5. 想把结论存档：`/save 合同审查意见`。

**判读状态**：`/status` 里的「上下文: 约 X/Y tokens」显示当前占用与自动摘要线（窗口的 80%）。

**摘要会缓存**：同一份文件第二次上传会直接复用上次的分段摘要，不重新计算；文件内容改动后缓存自动失效。
缓存写在 `app\backend\summary_cache.json`（可读 JSON，直接删除即可清空），
不想用缓存可在 `app\backend\config.json` 里把 `summary_cache` 改为 `false`。

## 四、场景二：批量审核网页上的合同（自动化）

**目标**：某个系统的任务列表里有若干任务，每个任务挂着合同附件，需要逐个下载并生成审核意见。

### 4.1 一次性配置（设置窗口 → 自动化）

| 字段 | 填什么 | 示例 |
| --- | --- | --- |
| 任务列表网址 | 列出全部任务的页面 | `https://oa.example.com/tasks` |
| 任务列表元素位置 | 指向「任务链接」的 CSS 或 XPath | `a.task-link` 或 `//a[@class='task']` |
| 任务行容器（可选） | 分页/行级定位用 | `table.task-table tr` |
| 下一页按钮（可选） | 翻页 | `a.next-page` |
| 任务详情页文件元素位置 | 指向附件链接 | `a.attachment` |
| 需要预览的文件后缀 | 逗号分隔 | `pdf, docx, xlsx` |
| 任务指令 | 交给模型的提示 | 「摘取合同的主要信息并生成财务审核意见」 |

填完点**「测试选择器」**：程序会打开浏览器访问该网址，把匹配到的元素文本与链接
预览在日志里——**先确认能匹配到正确的元素，再开启运行**。

### 4.2 安全协议
勾选「我已阅读并理解上述安全协议」后，自动化开关才可用（后端会强制校验）。
协议版本与你的同意时间会记入 `app\backend\automation_log.jsonl`。

### 4.3 运行
- 点「▶ 立即运行一次」；
- 浏览器会**有头打开**（你能看到全过程），逐个任务：进入详情 → 下载符合后缀的文件 →
  本地解析 → 交给本地模型生成摘要与审核意见 → **删除该任务的临时文件** → 下一个；
- 过程中日志实时刷新（也能在主窗口对话框看到）；
- 遇到**验证码或二次验证**会暂停并提示你手动完成（默认最多等 180 秒）；
- 想中止：设置窗口点「⏹ 停止自动化」，或回主窗口按 `Esc`；
- 单个任务失败会**截图存证并跳过**，不会中断整批（截图与失败原因都留在该任务的结果目录里）。

### 4.4 定时
勾选「启用定时」并填写每天的执行时刻（如 `09:00, 18:30`）。
定时任务由后端线程在程序运行期间触发；若希望开机自动执行，
请把「Start-EchoDesk-v0.2.1.lnk」复制到系统「启动」文件夹（`Win+R` → `shell:startup`）。

### 4.5 登录态
第一次需要你在浏览器里手动登录一次，程序会把登录态存到
`app\backend\browser_state.json`，之后自动复用。删除该文件即可退出所有登录。

## 五、场景三：安装技能扩展能力

1. `Ctrl+M` 打开设置窗口的**技能市场**；
2. 浏览或输入关键词搜索（输入后 300ms 自动搜索）；可切换「Star 最多 / 最近更新 / 最佳匹配」；
3. 卡片信息：
   - `✔ 已验证` = 仓库根目录有合法的 `skill.json`（含 `echodesk.bundle`）；
   - `⚠ 未验证` = 结构不合规，**安装按钮置灰**；
   - `● 已安装` = 本机已装，按钮变为「卸载」；
4. 点「详情」查看 README 摘要、版本、依赖、入口文件、是否含 prepare 脚本；
5. 点「安装」会弹出确认框，列出技能名、版本、来源链接与安全提示——
   确认后下载源码、校验清单、登记注册表。
   **EchoDesk 不会自动执行第三方脚本**；若技能声明了额外依赖，会在提示里列出，由你决定是否手动安装；
6. 「已安装」按钮可查看本机技能清单。

技能来源：**只从 GitHub topic `echodesk-plugin` 发现**。
搜不到结果通常是该 topic 下暂时没有仓库，而不是程序故障（详见 FAQ）。

### 本地插件与开发者模式

设置窗口「开发者」页的**开发者模式开关双向可用**：关掉就是关掉，重启后仍保持关闭。

- 关闭开发者模式会**卸载开发插件**并从指令表移除，同时清空开发日志 `app\backend\skills_dev.log`；
- 首次加载**第三方本地插件**（放在 `app\backend\skills_dev\`）会弹出**一次**汇总确认框：
  逐项列出插件的来源、路径与声明的能力、权限，可以**逐个勾选 / 全部启用 / 全部禁用**；
  你的选择会被记住，拒绝过的插件下次不再询问；
- **随包示例插件**（`examples\skills\` 下的 Hello World 与 OFD 读取）默认启用，不弹确认框。

## 六、联网与隐私速查

| 功能 | 是否联网 | 发送什么 |
| --- | --- | --- |
| 普通问答、文件解析、长文档摘要 | ❌ 完全本机 | — |
| 模型下载 | ✅ 仅在你同意后 | 只下载，不上传任何内容 |
| 联网搜索（`/search on`） | ✅ 你手动开启后 | 当次提问关键词 → DuckDuckGo |
| 技能市场 | ✅ 打开市场时 | 搜索关键词 → GitHub API |
| 自动化 | ✅ 访问你填写的网址 | 仅在你配置的目标站点内操作 |

除以上之外，**没有任何遥测、埋点或崩溃上报**。详见 `docs/PRIVACY.md`。

**合规文档**：输入 `/about` 会显示版本号、出品方，以及这些文件的**本机实际路径**——
外层根目录的 `LICENSE`、`NOTICE`，与 `docs\PRIVACY.md`、`docs\EULA.md`、
`docs\THIRD_PARTY_LICENSES.md`、`docs\SBOM.json`。完整合规文档还包括 `docs\SECURITY.md`、
`docs\zh-Hans\COMPLIANCE.md` 与 `docs\en\COMPLIANCE.md`。

## 七、键盘与效率

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Enter` | 发送 |
| `Enter` / `Shift+Enter` | 换行 |
| `Esc` | 停止生成 / 关闭指令列表 |
| `Ctrl+L` | 清空对话 |
| `Ctrl+O` | 上传文件 |
| `Ctrl+Shift+C` | 复制全部对话 |
| `Ctrl+滚轮` / `Ctrl+加/减/0` | 调字号 / 重置 |
| `Ctrl+T` | 切换浅色 / 深色（三态在设置窗口「常规」页） |
| `Ctrl+,` | 打开设置 |
| `Ctrl+M` | 打开技能市场 |

**主题（三态）**：设置窗口「常规」页可选**跟随系统 / 浅色 / 深色**。选「跟随系统」时跟随 Windows 的
应用模式，你在系统里切换浅色/深色时界面会立刻跟着变。快捷键 `Ctrl+T` 在浅色与深色之间切换，
也可以直接用 `/darkmode on|off|auto` 指定。

**emoji 显示（三态）**：设置窗口「常规」页可选**自动 / 始终显示 / 不使用**。选「自动」时，
本机缺少 emoji 字体的话界面会自动改用纯文本标记（`[OK]` / `[!]`），而不是显示方块。

**状态区**：输入框下方一行实时刷新——搜索开关、自动化、技能市场、上下文占用、KV Cache 估算，
以及**模型能力项**（参数量 · 量化 · 可用窗口 · 实测生成速度）：

- 点「🧠 模型…」打开「设置 → 模型」查看完整能力与推荐配置；
- 模型能力边界被触到时（窗口偏小、生成速度过低、KV Cache 超过本机内存的一半等）才会出现
  「⚠️ 能力提示 N」按钮，点开逐条列出原因与可采取的动作；
- 点「🗜 压缩上下文」等同于执行一次 `/compact`。

**指令面板**：输入 `/` 会弹出指令列表，`↑↓` 选择、`Tab` 补全、`Enter` 执行。
左下角「+」可把输入框里的 `/xxx` 转移到独立的指令输入行。

**常用语**：点「📋 打开常用语选择框」一键插入模板；
用 `/snippet add 名称 文本` 新增、`/snippet list` 查看、`/snippet remove 名称` 删除。
