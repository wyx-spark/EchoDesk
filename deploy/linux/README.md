> 本文件是**单文件双语**（中英并排），不是成对文档：它只有一屏，拆成两份反而更难对照。
> This file is intentionally **bilingual in one place** rather than a pair: it is one screen

> 图标与桌面条目的安装位置与生成方式见 `tools/gen_platform_icons.py`（三平台资源由同一个工具产出）。

## 一、这个目录里有什么 / What is in this directory

| 文件 / File | 用途 / Purpose |
| :--- | :--- |
| `echodesk.desktop` | freedesktop 桌面条目（开始菜单里那一项）/ the desktop entry (the launcher in your menu) |
| `com.voidentropia.echodesk.metainfo.xml` | AppStream 元数据（软件中心展示用）/ AppStream metadata for software centres |
| `../..  /assets/icons/hicolor/` | 各尺寸图标（生成物，不是手放）/ the per-size icons (generated, not hand-placed) |

图标与这两个文件都由 `python tools/gen_platform_icons.py` 生成 —— 改了 `assets/EchoDesk.ico`
之后要重跑它，否则图标会与 Windows 版不一致（`python tools/gen_platform_icons.py --check` 会报出来）。

The icons and both files are generated by `python tools/gen_platform_icons.py`. After changing
`assets/EchoDesk.ico` you must re-run it, otherwise the Linux icons drift from the Windows one
(`--check` catches exactly that).

## 二、便携用法（推荐）/ Portable use (recommended)

本项目在 Linux 上**没有系统级安装包**：发布物是压缩包，解压即用，自带解释器与运行时，
目标机不需要装 Python 或 .NET。

There is **no system package** for Linux: the release asset is an archive that just runs, with its
own interpreter and runtime bundled. The target machine needs neither Python nor .NET.

```bash
# 1) 解压 / unpack
tar -xzf EchoDesk-v0.2.2-linux-x64.tar.gz
cd EchoDesk-v0.2.2-linux-x64

# 2) 校验（可选但建议）/ verify (optional but recommended)
sha256sum -c SHA256SUMS.txt     # 该文件随发布物一起提供 / ships next to the archive

# 3) 启动 / start
./start.sh
```

如果解压时丢了可执行位 / if the executable bit was lost during extraction:

```bash
chmod +x start.sh app/EchoDesk
```

想让它出现在应用菜单里，把桌面条目指到你的解压路径即可（**不要**改 `echodesk.desktop` 本体，
它是生成物；复制一份到你的用户目录再改）：

To get it into the application menu, copy the desktop entry into your user directory and point it
at *your* unpack path (**do not** edit the generated `echodesk.desktop` in place):

```bash
mkdir -p ~/.local/share/applications
sed "s|^Exec=.*|Exec=$PWD/start.sh|" deploy/linux/echodesk.desktop \
    > ~/.local/share/applications/echodesk.desktop
update-desktop-database ~/.local/share/applications 2>/dev/null || true
```

## 三、系统级用法（可选）/ System-wide use (optional)

```bash
# 程序装到 /opt/echodesk（用你的解压路径）
sudo mkdir -p /opt/echodesk
sudo cp -r ./* /opt/echodesk/

# 图标：直接拷整棵 hicolor 树
sudo cp -r assets/icons/hicolor/* /usr/share/icons/hicolor/

# 桌面条目与 AppStream 元数据
sudo cp deploy/linux/echodesk.desktop /usr/share/applications/
sudo cp deploy/linux/com.voidentropia.echodesk.metainfo.xml /usr/share/metainfo/

# 刷新缓存（不同发行版命令不同，缺哪个就跳过）
sudo update-desktop-database /usr/share/applications 2>/dev/null || true
sudo gtk-update-icon-cache /usr/share/icons/hicolor 2>/dev/null || true
```

`echodesk.desktop` 的 `Exec` 默认就是 `/opt/echodesk/start.sh`，所以装到这个路径时不用改。
The shipped `Exec` defaults to `/opt/echodesk/start.sh`, so no edit is needed for that path.

## 四、用户数据在哪里 / Where your data lives

发布物是**便携布局**：解压目录下 `app/` 里是程序本体，用户数据（对话记录、设置、常用语、
`results/`）就在解压目录的**外层**。只有当你把程序装到 `/usr` 之类的位置、程序目录不再叫
`app/` 时，才会退到平台惯例目录。

The bundle uses a **portable layout**: `app/` holds the program, while your data (history,
settings, snippets, `results/`) sits in the outer unpack directory. The per-platform fallback
below only applies when the program folder is *not* named `app/` (e.g. installed under `/usr`).

| 平台 / Platform | 用户数据目录 / data root |
| :--- | :--- |
| Windows | 程序目录本身（安装版/便携版里就是发布目录外层）；**不是** `%APPDATA%` |
| macOS | `~/Library/Application Support/EchoDesk`（仅当程序目录不是 `app/` 时） |
| Linux | `~/.local/share/EchoDesk`（设了 `XDG_DATA_HOME` 时为 `$XDG_DATA_HOME/EchoDesk`） |

> 各平台的判定顺序（三处实现必须一致：后端 `backend/config.py` 的 `user_data_root()`、
> Avalonia 的 `frontend-avalonia/.../Services/UserPaths.cs`、WPF 的 `ShortcutService`）见
> `docs/zh-Hans/CROSS_PLATFORM.md` 第五节。`%APPDATA%` 只在若干**过时注释**里出现过，
> 代码里没有这条路径 —— 以代码为准。

`ECHODESK_DATA` 环境变量可以把它指到任何位置（三平台通用、优先级最高）。
The `ECHODESK_DATA` environment variable overrides it everywhere (all three platforms, highest
priority).

## 五、中文字体与 emoji / CJK fonts and emoji

Linux 上如果界面里的中文显示成方块、或 emoji 变成单色方块，通常是**缺字体**，不是程序缺陷：

If Chinese text renders as boxes, or emoji collapse into monochrome squares, you are usually
missing fonts — not looking at a bug:

```bash
# Debian / Ubuntu
sudo apt install fonts-noto-cjk fonts-noto-color-emoji

# Fedora / RHEL
sudo dnf install google-noto-sans-cjk-fonts google-noto-color-emoji-fonts

# Arch
sudo pacman -S noto-fonts-cjk noto-fonts-emoji
```

窗口类程序需要 X11 或 Wayland；纯服务器上没有图形环境，此时可以用
`app/backend/run-backend.sh` 手动启动后端做协议级排障（它按 JSON 行协议收发）。

The GUI needs X11 or Wayland. On a headless server, start the backend on its own with
`app/backend/run-backend.sh` and talk the JSON-lines protocol to it.

## 六、这个版本还没有的东西 / What this version does not have yet

如实说明，避免你在系统里找不存在的东西 / stated plainly so you do not hunt for things that
are not there:

* **没有 `.deb` / `.rpm` / AppImage**：需要 `appimagetool` 与 AppDir 结构，尚未自动化。
* **没有代码签名**：Linux 不要求，但也没有仓库签名。
* **没有在真实 Linux 上跑过的运行级证据**：发布物是在 Windows 打包机上交叉准备的，
  只做了结构级与静态二进制级校验（详见 `docs/zh-Hans/CROSS_PLATFORM.md` 第七节）。
* **图标源素材最大 256×256**：`hicolor` 里没有 512 目录，高分屏下会被系统放大（略糊）。
  要真正的高分屏图标需用矢量源重新导出。
