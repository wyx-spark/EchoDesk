# EchoDesk 隐私政策

版本：v0.2.0
生效日期：随本版本发布之日
出品方：Void Entropia Studio

## 一句话概括

**EchoDesk 是本地 AI 桌面助手：模型推理、文件解析、对话记录全部在本机完成，
不上传你的文档、对话或任何个人数据。** 只有你主动开启的功能才会产生网络请求，
且请求内容在下面逐项列明。

---

## 一、默认不联网的行为

以下操作**完全在本机进行，不产生任何网络请求**：

| 操作 | 说明 |
| --- | --- |
| AI 对话与推理 | 由本机 llama.cpp 加载本地 .gguf 模型完成，输入与输出都不离开本机 |
| 文件上传与解析 | Word/Excel/PPT/PDF/TXT 在本机解析，长文档在本机分段摘要 |
| 长文档分段摘要 | 用本机模型逐段摘要，不调用任何云端服务 |
| 对话历史保存 | 保存在程序目录的 `backend\session.json`，仅本机可读 |
| 常用语、界面状态 | 保存在 `snippets.json`、`ui_state.json`，仅本机可读 |
| 自动化任务执行 | 用本机安装的 Microsoft Edge 打开你指定的网址，浏览器操作由本机完成 |

## 二、会联网的功能（均为你主动开启）

1. **模型下载**（首次启动或 `/model` 切换模型时）
   - 触发方式：程序询问后你点了「是」。
   - 请求内容：向 Hugging Face（默认走 `hf-mirror.com` 镜像）请求模型仓库的文件列表与 .gguf 文件。
   - 不发送：你的对话、文件、任何本地路径或个人信息。
   - 上传数据：无（仅下载）。

2. **联网搜索**（`/search on` 后提问）
   - 触发方式：你手动开启搜索开关。
   - 请求内容：把你当次提问的关键词提交给 DuckDuckGo 搜索。
   - **注意**：此时提问关键词会离开本机，请勿在开启搜索时提问敏感内容。
   - 关闭方式：`/search off`（关闭后提问完全本地）。

3. **技能市场**（设置窗口 → 技能市场）
   - 触发方式：你打开市场页面或点击搜索。
   - 请求内容：向 GitHub Search API 查询 topic 为 `echodesk-plugin` 的仓库（关键词、排序、分页）。
   - 可选：填入 GitHub Token 可提高 API 限额；Token 仅保存在本机配置文件，不随任何请求外发到 GitHub 以外的地址。
   - 安装技能时：从 GitHub 或 npm/PyPI 下载技能源码包到本机。

4. **浏览器自动化**（设置窗口 → 自动化）
   - 触发方式：你勾选安全协议并开启自动化开关，或点击「立即运行一次」。
   - 请求内容：访问**你自己填写**的任务列表网址，以及该页面上你指定的文件下载链接。
   - 数据去向：仅流向你配置的目标站点；EchoDesk 不向第三方回传任务内容、下载文件或审核意见。
   - 下载的文件保存在本机临时目录，处理完成后删除。

> 除上述四项外，EchoDesk **不含任何遥测、埋点、崩溃上报或使用统计**。

## 三、日志与脱敏

- 崩溃日志 `backend\backend_crash.log`：仅记录 Python/原生异常的堆栈，用于排查启动问题。
- 自动化审计日志：记录「谁、何时、执行了什么任务、下载了哪些文件（仅文件名）」，用于审计追溯。
- **脱敏规则**：日志中不写入文件正文内容、模型输出正文、GitHub Token、Cookie、密码或任何表单输入值；
  超长字段一律截断，路径中的用户目录按需省略。
- 日志全部保存在本机程序目录，不自动上传。

## 四、临时文件与内存清理

- 自动化下载的文件统一放在系统临时目录的 EchoDesk 专用子目录，任务处理完成后立即删除；
  程序异常退出时残留的临时目录会在下次启动时清理。
- 浏览器登录态（Cookie / localStorage）保存在程序目录的 `browser_state.json`，
  你可以随时删除该文件以退出所有已登录站点；卸载时随程序目录一并删除。
- 推理过程使用的 KV 缓存位于内存，进程退出即释放。

## 五、你的控制权

- 删除 `backend\session.json` → 清除对话历史。
- 删除 `snippets.json` → 清除常用语。
- 删除 `ui_state.json` → 重置窗口状态与首次引导标记。
- 删除 `backend\models\*.gguf` → 移除本地模型（再次使用会重新询问下载）。
- 删除整个程序目录 → 等同于完全卸载（便携版不写注册表；安装版通过卸载程序完成）。

## 六、儿童与合规

EchoDesk 面向成年专业用户设计。使用自动化功能访问第三方站点时，你需自行确认该行为符合
目标站点的服务条款与你所在组织的规章制度。

## 七、政策变更

本政策如有变更，将在新版本的 `docs/PRIVACY.md` 与本文件（发布物内的说明文件）中同步更新，
并在变更日志中注明。
