# EchoDesk Support / 支持

## English

For help, see the README, docs/ folder, and GitHub Issues. No support email or phone number is provided.

Usage questions, bug reports and feature requests all go through GitHub Issues. When you report a
problem, include the version shown in the title bar, the operating-system platform, and the exact
step that failed; that is the information a maintainer needs to reproduce it.

## 简体中文

如需帮助，请查阅 README、docs/ 目录和 GitHub Issues。本项目不提供支持邮箱或电话。

使用问题、缺陷反馈与功能请求统一通过 GitHub Issues 处理。反馈问题时请附上标题栏显示的版本号、
操作系统平台以及失败的具体步骤 —— 这些是维护者复现问题所必需的信息。
